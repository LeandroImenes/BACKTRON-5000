# BACKTRON-5000
Projeto visando facilitar a criação de um back-end

## Como testar
- Clone este repositório
- Execute o arquivo BACKTRON-5000.bat (caso o Windows não permita a execução, clique em <kbd>Saiba Mais</kbd> e depois em <kbd>Executar mesmo assim</kbd>
- Digite o nome do projeto
- Cole o código em .sql do seu banco de dados
- Veja seu back-end sendo criado em segundos!
